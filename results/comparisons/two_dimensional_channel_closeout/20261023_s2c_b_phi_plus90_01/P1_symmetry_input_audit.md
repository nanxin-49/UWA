# PHI_PLUS90 左右对称性输入审计（2026-10-24）

本审计只读冻结接收坐标、源谱与数值配置，用既有 MATLAB MCP 会话评价解析海面；没有运行入射场、BIE、PE 或 FullFK 声学核。它只确认 M05e 将来可用的配对坐标及几何对称性，**不是复场对称性或物理机理的证明**。

| 输入或网格 | 实测结果 | 对 M05e 的含义 |
|---|---|---|
| 冻结 417 接收点 | 417/417 均能在同深度找到 −x 对点；其中 x=0 有 3 点 | 可以在全部原生点上做同深度的 ±x 配对，不需插值 |
| PE 原 N=984 FFT 横向网格 | 983/984 有 −x 网格点；唯一不配对的是 −96.09375 m Nyquist 端点 | 比较时单独排除 Nyquist 端点，不把离散网格视为严格左右对称 |
| 五层 BIE Gauss8 配置 | 节点数依次 3840、3840、4480、3200、3736；反向相加的最大 x 偏差分别为 5.55e−17、5.55e−17、8.88e−16、2.22e−16、2.22e−16 m | 五层边界网格均按相同 ±x 配对方式采样 |
| 五层 PHI 解析海面 | 各层 `max|η(x)−η(−x)|≤2.78e−17 m`、`max|η′(x)+η′(−x)|≤3.04e−18`；`|x|≥50 m` 的高度严格为零 | PHI 的 cos 型高度为偶、坡度为奇，解析平面外场前提保留 |
| 冻结离散源谱 | FFT 顺序配对的 ±kx 系数最大差 2.35e−15，非零 Nyquist 单项约 6.76e−5 | 源谱近似左右配对，但不能事先断言实际复场严格对称 |

复核方法：用 `formal_reference_v2/reference_data.mat` 的 `(x,z)` 对 `(-x,z)` 做精确行匹配；PE 网格直接按冻结的 `W=192.1875 m,N=984` 构造；BIE 网格沿用求解器的 `panel_count=ceil(2L/(λ·8/ppw))`、对称 `linspace(-L,L,panels+1)` 和 Gauss8 节点；在这五组节点上调用 `closeout_s2c_b_surface(x,.05,.1,pi/2)`，再与逆序点比较。对应节点数与 PHI BIE 运行入口一致。上述偏差仅为浮点舍入级别。

BASE_M 为奇对称高度，PHI 为偶对称高度；将来的 M05e 应先在**实际计算的原生复场**上画成对位置和残差，再讨论左右结构。物理源、边界条件及离散实现可能破坏严格场对称，不能以本输入审计替代数值场验证。
