## 源、坐标和历史尺寸

条带沿y无限延伸，真实振面在z=100 m，总宽W，中心x=0。x水平，z向下。向上法向速度峰值v0=0.001 m/s，c=1500 m/s，rho=1025 kg/m³。所有幅度保存为未归一化的峰值Pa。

历史“5 cm”来自 `run_piston_frequency_minimal_comparison.m` 的 `radius_m=0.05`。GitHub固定提交和本地历史均已在quicklook报告核对。因此本轮辅助源采用二维半宽5 cm、总宽10 cm，圆形与条带采用各自维度的物理定义。[历史参数固定提交](https://github.com/nanxin-49/UWA/blob/f3314fded85993832771f48e398f2a79edee582a/scripts/comparisons/run_piston_frequency_minimal_comparison.m#L12)

时间因子为 exp(-i omega t)，k=omega/c，s=100-z，R=sqrt((x-xi)^2+s^2)，C=rho omega v0/2。在上方辐射半空间使用

```
p   = C integral[-W/2,W/2] H0^(1)(kR) dxi
p_x = -C k integral H1^(1)(kR) (x-xi)/R dxi
p_z = +C k integral H1^(1)(kR) s/R dxi
v   = grad(p)/(i rho omega)
```

因此振面水侧向上速度对应v_z=-v0。压力单位Pa，梯度Pa/m。phase contract v2使用显式表示元数据，物理载波按真实传播距离恢复，再作DSP转换。接收线z=3 m，x从-40至40 m，0.05 m与0.025 m分别保存1601与3201个点。

## PE表示的失败与修正

最初512 m周期初场的压力接近参考，但谱梯度失败。8192 m时10 cm/6 kHz仍为1.42119e-4，超过1e-4门。32768 m才使全部六组通过。原数据与失败门保留。

P1直接周期截窗传播即使4096 m仍未收敛，窗口差约0.08152、初场偏移差0.01013。不能将该结果用于反射模型解释。随后在验证工作流内使用同一平方根PE传播算子的连续角谱实现，完整处理条带的传播和倏逝谱，保持 exp(i(k_z-k)ds) 与真实载波恢复。初场平面1/2 m偏移均检查。1024/2048角谱节点及半步长检查后，采用2048节点、步长0.09375 m、偏移2 m。公开WAPE核心与Gaussian生产默认配置保持原有实现。

平面/弱海面PE采用精确平面外部背景加紧支撑Model-0相屏扰动

```
p_R = p_mirror + propagate[(1-exp(-2 i k eta(x))) p_inc(x,0)]
```

扰动采用同一平方根算子。平面eta=0时扰动严格为0，平面PE误差0包含这一解析构造含义。相屏部分检查128/256/512/1024 m窗口，dx0.05/0.025 m、步长0.1875/0.09375 m。尾部截断按评价深度控制指数衰减，记录在元数据中。
