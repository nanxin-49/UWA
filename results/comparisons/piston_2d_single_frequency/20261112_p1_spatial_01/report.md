# P1 弱 C2 海面二维反射复场图

2026-11-12。远程 MATLAB R2025b Update 1，单线程。从已通过的 `20261112_remote_p0p1_01` 保存数据评价总宽20 cm条带活塞在4 kHz弱C2正弦海面下的空间场。

![PE、BIE、FullFK二维反射声场与复差](output/weak_spatial_03/weak_reflected_spatial_20cm.png)

图的空间范围为x∈[-40,40] m、z∈[0.5,10] m，步长分别为0.5 m与0.25 m。上排为三模型绝对反射声压峰值，使用相同的0–50.0895 Pa色标。下排是复场绝对差 `|p_PE-p_BIE|`、`|p_FullFK-p_BIE|` 以及相位差 `arg(p_PE conj(p_BIE))`，各误差子图使用自己的色标。白虚线为原P1接收线z=3 m。弱海面仍为A=0.01 m、K=0.10 rad/m，|x|≤42 m为平台，至50 m平滑归零。

计算直接读取原P1保存的PE相屏输入、BIE边界密度和FullFK源/800面板配置，在二维网格评价各自的复场。BIE使用相同half-plane Green核与已存密度，FullFK保留完整双项积分、真实法向和弧长以及解析平面外部贡献。PE用保存的紧支撑相屏输入和相同平方根传播因子，再加解析镜像背景。图中二维场逐网格点计算，未由接收线插值生成。

网格z=3 m行与原已接受P1接收线复场的相对差分别为PE `8.493e-16`、BIE `1.007e-16`、FullFK `1.655e-17`。全图最大反射幅度50.0895 Pa，PE/BIE最大复差0.80197 Pa，FullFK/BIE最大复差1.5434e-4 Pa。这些是图示空间范围内的最大绝对差，原P1报告的0.4893%与0.0002095%仍是z=3 m整线相对L2，指标定义不同。

复声压数组、坐标和海面数据保存在 [`spatial_complex_fields.mat`](output/weak_spatial_03/spatial_complex_fields.mat)。同名PNG/FIG及运行回执保存在 `output/weak_spatial_03/`。`SHA256SUMS`校验43个源码、图、数据和日志文件，本地复验0项失败。最初FullFK回调接线错误及第二次启动器源码路径错误分别保存在`process/`与`process_v2/`，两次退出码均为1；通过的第三次任务记录在`process_v3/`，退出码0。

本图是此前已接受P1配置的空间重评价。原P1的数值资格检查针对z=3 m接收线，本次二维网格未再进行独立的空间网格和BIE/FullFK离散收敛研究。严格二维、均匀介质、单个弱正弦海面与验证专用PE表示仍为适用范围。
