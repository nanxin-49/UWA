## 2. 优化范围与等价性门

未来获准实施时，建议先在验证helper增加默认关闭的缓存选项和可选阶段计时，公开生产入口与源默认保持原状。计时至少区分：输入/几何、普通矩阵组装、近面板替换、右端、稠密求解、411点评价、全平台边界残差、保存。计时信息作为新增元数据，不重命名既有输出。

第一批只做不改变数学公式的复用：

1. 按阶数缓存Gauss节点/权重，按节点缓存重心权重，按准确的目标模板缓存Lagrange基。规则使用原`eig`生成方式，不另换求积库。
2. 每次BIE调用建立自己的源面板几何表，复用普通和奇异求积位置上的高度/坡度/法向/弧长/窗口。使用原始实际`edges(ps)`和`edges(ps+1)`；不因均匀网格而另用一个近似公共半宽重算所有坐标。
3. 普通模板、8种节点奇异模板与中点奇异模板分开。函数句柄/PM系数变化时重建几何；不跨seed或跨配置盲用persistent几何缓存。
4. 仅在同网格、同L/波数/半平面/几何/窗口条件完全一致的qa96→64分支，允许在同进程复用尚未做近面板替换的GL8基础矩阵。qa改变后必须重新替换相应块、重新分解和求解；不能复用最终A/LU冒充qa敏感性。该项可在阶段计时证明有价值后实施，成本模型不预先计入收益。

首轮不引入FMM/低秩、迭代近似、GPU、single、对称性假设、降低qa、减少接收点或边界点，也不以Fourier拟合/插值代替真实411点评价。不更改组合层、半平面Green核、对角跳跃项、真实法向、C2嵌入或压力/相位定义。若将来尝试批量化远面板核计算，单列第二优化版本，重新通过等价性门，不能默认为本方案已验证。

等价性按两级验证，全部是**未来步骤，今天未运行**：

- **小规模实现对照**：使用相同PM和源、L60、ppw0.2/0.4（N64/N128，仅代码等价性，不作物理参考）、面板GL8、qa64/96，对原实现/缓存关闭/缓存开启逐项比较。小规模临时诊断可保存A、右端与密度。A及右端相对差≤1e-12，密度与411点反射场相对差≤1e-11；边界残差向量的差用边界驱动范数归一化≤1e-10。不能用接近零的残差自身作分母。原分支输出保持原行为。
- **原N3200全配置回放**：缓存开启重新求解上轮完全相同的L60/ppw10/qa96，与已封存的源/几何、密度、411点修正场及完整反射场对照，密度/复场相对差≤1e-11。仍须线性残差<1e-10、全部离节点边界残差<1e-4。用该回放同时测量成本；不能用小网格速度推断完整问题速度。旧A没有保存，因此不声称已完成历史全尺寸A逐元素对照。

任一等价性检查失败就停止该优化版本。不得将实现改动误差混入PS/FullFK物理模型误差，也不自动放宽上述优化等价性门。

继续沿用原经验参考分辨口径：将四个BIE配对的逐点差绝对值相加得到`bunc`，保留原PS与FullFK敏感性，按`5*norm(bunc+model_unc)/norm(BIE_final)`判定是否分辨。即使单项都<1e-4，也不能预先保证FullFK差可分辨。分辨率缺失时报告unknown，不以`false`冒充“已证明不可分辨”。

## 4. 有界成本校准与派发门

上轮累计439 s，1100 s总额下的**名义余额为661 s**，不是停止时的773 s，也不是新增1100 s。本轮用户只授权分析，余额不构成当前执行许可；未来恢复必须获明确的实施/执行指令。推荐先尝试在原累计上限内闭合，不自动申请或消耗新预算。

建议未来串行使用一个R2025b单线程进程，最多允许两个的旧上限保持不变，但本方案不靠并行降低累计进程秒数。减少重复启动和重复图件生成；每个逻辑阶段仍独立保存日志/回执/检查点。一进程中只在关口通过后继续，不能一条无条件脚本跑完全部层。

| 阶段 | 许可内容 / 成本门 |
|---|---|
| S0，拟预留40 s | 启动/身份与SHA检查、小规模等价性检查；超过门或失败则停，不派发完整参考 |
| S1，校准C0 | 仅一层完全同配置回放，保存分阶段计时。建议该校准子阶段硬上限120 s，且受661 s总余额约束；超时先保留/核验原作业，不自动重试 |

| S3，拟预留110 s | 新密度/边界/411点独立重建、MAT/CSV、经验分辨率、必要新图、FIG重开与SHA封存；尽量一次生成交付图，原PS/FullFK声场不重算 |

静态预算筛查用原N3200缓存回放实测函数时间`t`作为校准量。尚未有阶段测量时，暂以N³和25%规划余量投影余层，不给qa64预支加速收益：

```
余下四层系数 S = 2*(3840/3200)^3 + 2*(4480/3200)^3 = 8.944
候选新增进程预算 ≈ 40 + t + 1.25*S*t + 110
                = 150 + 12.18*t  秒
```

| 假设优化回放t / s（非实测） | 含校准与收尾的规划量 / s | 661 s名义余额 |
|---:|---:|---|
| 30 | 515.40 | 规划上可容纳 |
| 40 | 637.20 | 余量很小 |
| 42 | 661.56 | 超出，停止 |
| 60 | 880.80 | 超出，停止 |
| 90 | 1246.20 | 超出，停止 |

因此，采用这一保守筛查时，C0回放需约**41.95 s以内**才具备继续派发全部原层级的规划条件；这相当于相对旧函数254.689 s约6.1倍提速要求，**尚无实测证据证明能够达到**。小于该值也不是预算保证。S0实际耗时、进程启动、保存、失败、各阶段计时和任务结束耗时都计入真实累计账；超出40 s等规划占位时用实际值替换，余额只能减少。

得到分阶段计时后，可分别对组装/边界求积按N²、稠密分解按N³投影，并记录新模型版本和误差余量；不可只因为单层快就取消未测层的风险预留。若预测仍装不进661 s，停止在校准/已完成层，返回实测分段成本，由用户审查是否另定预算；不自动把`used`重置为0或把总额改成1100+1100。

资源与守门要求：

- 保留原单进程900 s、至少30%启动可用RAM、最多两个独立单线程、无parpool。实际建议一个进程；总预算计所有进程启动到退出的墙钟秒之和。
- 校准120 s硬上限不是获准运行120 s的预算。进程外还须设置`min(900,剩余累计预算)`上限，阶段截止时间从同一计时起点累计，不靠清零计时续命。
- 原launcher循环只是采样RAM并在派发前检查，没有在求解中低RAM时主动执行停止。本次原运行采样未触门；未来续行应补上任务自有进程/批次的RAM和时间中止检查，保存停止原因，不终止其他用户或无关MATLAB会话。
- 可继续采用每进程12 GiB的保守RAM准入估计，并按新增矩阵/缓存的实测修订；它不是已证实的峰值上界。缓存只存必要几何/模板，不能持久化所有目标×源高阶核张量。
- N4480的一份complex-double稠密矩阵约306.25 MiB。qa分支即使复用基础矩阵，修改时仍可能触发完整复制，LU还需工作区；记录峰值RSS并逐层审查，不以旧1.13 GiB直接保证新层安全。
