# α=2.5 计算域收敛与条件性 FullFK 对照预设协议

本轮只沿用 `deepsea3d_alpha25_fine/fine.mat` 中通过的冻结 cfg 和 L24、
h=.0625、N20（以及已保存 N16）参考。Tx(0,0,1500)、Rx(0,0,5)、q=0、
6 kHz、c1500、dual 振幅(.05,.025) m、波矢(.4,0)/(.2,.6)、phase(.2,.7)、
C2 plateau8/support12 m、exp(-iωt) 及压力释放边界不变。
L 是 Fourier 计算域半宽，扩域只增加外围平面区域，不缩放或重新采样物理参数。

## 先参考，后物理

1. L32/h=.0625/N20/M40，真实配点和双方向半网格边界；随后诊断回放。
2. 参考门保持 1e-4：相邻域的接收复增量变化、同网格 N16→20 部分和变化、
   N18→20 部分和变化、真实配点及半网格残差。沿用已通过的 L24 网格门。
   N20 最后五阶边界系数范数与压力项幅度必须递减；forcing 相对差 <1e-8，
   回放逐阶复压力/系数范数相对差 <1e-12；所有输出必须有限。
3. 若 L24→32 域变化失败、其余参考护栏通过，追加一次 L48/h=.0625/N20/M40
   及回放，以 L32→48 域变化判定。不继续超出 L48 或 N20。
   若任何其他参考门失败，或 L32→48 仍失败，停止并保留 INCONCLUSIVE，FK 零求解。
   N16 部分和是相同冻结递推在同一网格的准确低阶截断；无需重复独立 N16
   求解就能获得接收阶数对照，必要时才补充单独 N16 边界诊断。
4. 记录 h 归一化边界系数范数、最后五阶及跨域尾部变化，内部贡献范数和/
   结果范数（诊断指标，不是数学条件数），接收阶数求和指标。
   M40 指数求值尾界单列，不声称是连续 PDE 或 FE 余项界。

参考通过后才调用未改动的 `solve_deepsea3d_fullfk`，五个固定数值检查：
A16/h=.05/trap、A16/h=.025/trap（主 FK）、A16/h=.05/gauss4、
A12/h=.025/trap、A24/h=.025/trap。A 是积分正方形半宽，与 FE 的 L 分开。
积分为解析无限平面 + 紧支撑完整粗/平密度差；所有 A 均覆盖半径12 m物理支撑。
比较两个孔径变化和网格/独立 Gauss 求积，相对于非零粗糙增量各 <1e-3。
扩大 A 不改变海面，不能用有限原始平面积分当无限平面背景。

原生反射声压 P_ref 与 ΔP=P_ref−P_flat 分别计算复相对误差、幅度相对误差、
原始相位差（rad），不作幅相拟合。可信参考和 FK 数值护栏通过后，两项复误差
各 <1% 为 CONDITIONAL_G1_PASS，否则 CONDITIONAL_PHYSICAL_FAIL。
参考或 FK 自身数值未定一律 INCONCLUSIVE。

## 复现、冻结与成本

入口 `validate_deepsea3d_alpha25_domain`：init → next → observe → reference；
若 reference 追加 L48，则重复 next/observe/reference；之后五次 fk → audit。
各计算独立 checkpoint，init 拒绝覆盖。status 只读；audit 重算护栏及输出表。
数据保存在 `results/validation/deepsea3d_alpha25_domain/`。保留完整复数 terms、
partials、残差、消项和配置；冻结哈希在运行前后核对。报告、协议、代码与新产物
另有 provenance。进程内存前后快照、保存谱载荷及 FK 块载荷明确不是峰值内存。
实际 wall/CPU 分开，旧 L24 历史成本零新增计入，IO/分析/文档耗时不混入核成本。

只认证该离散案例；全 G1 目标域 OPEN，WP2=false。不改冻结求解器、生产 PE、
二维基准或旧验收数据，不开展更大振幅、PM、FastFK、宽带或 WP2。
