# P22 PE 相位屏二维宽带通信模拟闭环（2026-10-30）

## 结论与适用范围

**`PE_SCREEN_COMM_SIMULATION_PASS`**：在 `3D_try` 上，原冻结 Gaussian 源、平面/原弱 C2 正弦海面、P22、4–8 kHz PE 复频响经过独立 257 点核查，在**统一 64 ms 时窗**下满足 `≤1e-3` 的复频响/CIR 加密门；随后用冻结的真实 PE CIR 完成 QPSK 发送、线性信道卷积、接收、已知 CSI 均衡、解调与 BER/PER/EVM–SNR 曲线。状态仅属于 **二维 PE Model-0 相位屏近似模型的通信模拟闭环**。没有 BIE、FullFK 或三维计算；原正式 S5 A=`PARTIAL`、B=`BLOCKED`、S6 C=`BLOCKED` 不变。

原 65/129 **不同周期窗**的无窗 IFFT 比较 `0.0438747 >1e-3` 是保留的失败证据，不被追改。通过的门是事后明确、独立审计的**共同频率/时窗表示**：先按几何反射相对时延 4 ms 对直达/反射分量分别进行慢变包络插值，全部投影到同一 257 点、64 ms 频率/时窗，再以新求解的 257 点 PE 频响为独立对照。阈值仍是 `1e-3`，没有调整源、海面、P22、共同 `τ0=97/1500 s` 或旧原始数据。该新门的含义与原始无窗比较不同，不能把旧失败记录改写为旧方法通过。

## 声场、时域与折叠原因

原 65/129 点 PE 结果及设置见[初次报告](pe_screen_p22_broadband_comm_2026-10-30.md)。为追查 4.39% 差异，新增交错 256 个频点，得到 257 点/64 ms 平面与弱正弦频响，实际 PE 求解 `67.8041 s`。64 点 IFFT 与 128 点 IFFT 的嵌套网格满足 `h64[n]=h128[n]+h128[n+64]`，独立审计最大相对残差 `1.3343e-16`；所以原差精确来自后半窗折叠。257 点中，16–32 ms 能量分数仅 `1.09e-6`，32–64 ms 约 `0.0019002`，其中最后 4 ms 约 `0.0018877`。在有符号时轴中它位于零前，符合有限 4–8 kHz 矩形频带的前振铃/周期折叠；不能称作真实迟到达路径。详细分量、端点与非周期有限带宽积分见[诊断报告](pe_screen_p22_aliasing_diagnosis_2026-10-30.md)。

共同窗口门用频率 `4000:15.625:8000 Hz`，前 256 点 IFFT，原始采样 `0.25 ms`，有符号时轴 `[-32,32) ms`；同一 `τ0` 用于两海面和各分量，物理主能量支持检查为 `[-4,12) ms`。插值仅用于 65/129 网格的**预测**；257 点真实 PE 复数场独立求解且未用插值替代。检查与独立 MAT/CSV 重算见[共同窗口结果](../results/validation/pe_screen_p22_common_window/20261030_01/)。

共同窗口验收 `failed_check_count=0`，独立审计 `PE_SCREEN_COMMON_WINDOW_CIR_INDEPENDENT_AUDIT_PASS`，保存 CSV 与 MAT CIR 最大绝对差 `5.6644e-16`。无周期延拓积分的 65→129 差仍约 `4.73e-3`；这与共同窗口门使用的已验证路径时延解相位插值属于不同数值表示，不能混为同一个“原始 65 点 IFFT 已收敛”结论。

## 冻结 QPSK 链与性能

在共同窗口独立审计通过**之后**冻结 [`config.json`](../results/communication/pe_screen_p22_qpsk/20261030_03/config.json)，再运行 [`run_pe_screen_p22_qpsk.m`](../scripts/validation/run_pe_screen_p22_qpsk.m)。信道使用独立 257 点 PE 的完整 256 taps，统一 16 样本因果保护移位；4 ksps Gray QPSK，512 符号块、255 符号循环前缀、每帧 1024 bit，已知 CSI 块 FFT LMMSE 均衡。每海面、每 SNR 点 `262144 bit/256 frame`；`0/6/12/18/24 dB` 指**信道输出、均衡前**的平均样本 SNR。平面和弱正弦使用同一 bit 序列及配对噪声种子。无噪声控制使用精确 CSI 除法。没有脉冲成形、导频 CSI 估计、多普勒或真实海试噪声。

无噪声两海面均 `0` bit/frame 错，均衡复相对误差最大 `1.003e-14`；线性卷积核对最大 `1.882e-16`，循环前缀等价最大 `3.741e-16`。真实卷积链的 BER/PER/EVM 随 SNR 如表及[曲线](../results/communication/pe_screen_p22_qpsk/20261030_03/figures/ber_per_evm.png)所示；每点的 bit/frame 错数和 95% Wilson 区间保存在 `performance.csv`。配对 bit 错误的仅平面/仅弱正弦计数在 0、6、12、18、24 dB 分别是 `4/1、3/3、0/2、0/0、0/0`；两曲线本轮几乎重合，**没有证据宣称弱正弦造成可分辨的通信性能损失或改善**。低 SNR 的 PER 饱和为 1，24 dB 只有 2 个错帧/256 帧，PER 估计仍较粗。

[`audit_pe_screen_p22_qpsk.m`](../scripts/validation/audit_pe_screen_p22_qpsk.m) 用保存 MAT 重放全部 10 组配对噪声、均衡与解调，均衡符号逐值相同，CSV 指标最大差 `3.908e-14`，审计状态 `PE_SCREEN_QPSK_INDEPENDENT_AUDIT_PASS`。最终可复现实验包在[通信结果目录](../results/communication/pe_screen_p22_qpsk/20261030_03/)：配置、MAT、CSV、FIG/PNG、`run_stdout.log`、`audit_stdout.log`、两个 JSON 回执及 SHA 检查点。此前 `_01` 与 `_02` 作为保留的预运行/日志尝试，不覆盖；最终 `_03` 与 `_01` 的性能 CSV SHA 完全相同。所有运行均使用既有本地 MATLAB MCP R2025b Update 6；未在共享远端根同步或运行本项目，未自动提交/推送。

## 剩余限制与下一步 Goal Prompt

此模拟只检验固定 P22、两种固定海面和完美 CSI；其弱正弦差异很小，需更强的统计设计才能分辨通信效应。共同窗口的分量去相位插值依赖已知 4 ms 几何反射时延，不能无审计移用于其他几何、PM 样本或未知多径。真实 S5/S6 物理资格仍缺全带独立参考；本轮不改变它。

> 在不改变本次冻结声源、P22 和 PE 相位屏模拟结论的前提下，扩展配对 QPSK 试验的样本数与过渡 SNR 点，给出平面/弱正弦 BER、PER、EVM 的配对差置信区间；单独验证导频 CSI 估计和均衡失配对结果的影响。保留共同窗口 CIR 的 `≤1e-3` 门与原始不同窗 IFFT 失败记录，勿把此 PE 模拟 PASS 升级为正式 S5/S6 物理验收。
