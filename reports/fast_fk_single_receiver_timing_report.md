# 单接收点 FullFK 与当前 FastFK 效率对比

日期：2026-10-08。MATLAB 25.2.0.3312555 (R2025b) Update 6；共享 MATLAB 会话，CPU double。

仅新增一个单频、单接收点测试，未修改 FullFK/FastFK 算法，未运行 PE、BIE、新宽带或接收点数量扫描。

## 冻结配置

复用已通过的 `consistency.mat`：seed260001、12 个固定 PM Fourier 模式、Kmax=0.471238898 rad/m、C2 plateau42/support50 m。频率4000 Hz，c=1500 m/s，Tx=100 m，Rx=3 m；这是原研究夹具。

海面积分及 FastFK 接收网格均为 [-60,60] m、4097点，dx=120/4096 m；源为既有984点、sigma=0.3 m Gaussian，保留全部既有传播谱，精确 kz。高度界0.5 m，height nodes33，geometry B，rank_in/out=3/12，max_rank12，padding2（FFT8194）。直接复用保存 eta/slopes/source，所有 reference SHA256 均校验通过。

唯一接收点：MATLAB index2049，x=0 m，z=3 m，位于既有 M99 核心。FullFK 输入严格为标量 receiver_x/z，仅形成1×4097积分核；FastFK仍求4097点整场后提取此点。

## 实测时间与范围

两种方法的准备和求值各预热一次；9轮交替执行方法顺序，每轮准备一次、连续求值10次，批次总wall time除以10。下表为9轮中位数及[min,max]。外层tic/toc包含调用、输入检查和输出构造，Fast包含单点提取；不包含磁盘IO、hash检查、报告保存。

|阶段|FullFK严格单点 / s|FastFK整网格 / s|
|---|---:|---:|
|准备|0.1104937 [0.1014447, 0.1143341]|0.1789923 [0.1693065, 0.1998499]|
|实际计算（每次）|0.00098571 [0.000894, 0.0012516]|0.0360479 [0.03510304, 0.03943212]|
|准备＋一次计算|0.11155524 [0.1023387, 0.1155857]|0.21469579 [0.20475701, 0.23675958]|

Full准备：在全部海面样点上精确计算入射u/ux/uz并组装dn与标量receiver配置；Fast准备：既有incoming/outgoing SVD、Hankel lag核、插值与plan。Full求值中的弧长求积权重构造仍计入计算。输入准备不是单点Hankel积分本身，两者的准备内容不同。

公共输入文件读取 0.5735067 s，固定配置组装（含kz、normal）0.0043063 s，单独记录、不计入上述速度比。海面直接复用保存数组；其历史生成时间不在本轮计时内。准备＋一次计算是已预热实现下的plan重建成本，不代表首次启动MATLAB/JIT的耗时。

定义 speedup=T_Full/T_Fast：计算阶段 **0.02734445**；含准备 **0.51959677**。即Full单点计算比当前Fast整场快 **36.57倍**，含准备快 **1.925倍**。计算阶段绝对差 0.03506219 s；含准备差 0.10314055 s（各方法中位数之差）。

## 与此前整场测试对照

同一4 kHz保存记录：Full4097点准备/计算 0.1231122 / 2.2437772 s；Fast4097点准备/计算 0.1680723 / 0.0369028 s；warm/cold加速比 60.8024 / 11.5472。

此前Full整场计时为单次外层调用，Fast计算为预热后3次内部wall_seconds中位数，cold含各自准备、排除共同海面生成和IO。本轮Full只有1点，Fast仍4097点，双方使用相同外层计时且9批×10次。因此旧整场加速比只说明整场任务，不能拿来代表本轮单点任务；本轮并未重新测整场Full，也未混用旧耗时计算新速度比。

## 判断

当前实现用于此单浮标任务时，FullFK直接单点更快；FastFK整场加速优势不延续到单点。入射场已经可复用时，应看计算阶段；每次重建输入/plan时，应看含准备结果。两种范围均给出同一速度排序。

不建议仅为该固定单频单浮标场景继续优化当前整场FastFK，优先使用FullFK单点并复用固定入射数据。若以后另有大量重复查询且可长期摊销plan的需求，才值得另立单点算法研究；本轮未测该需求，不能推算其收益或交叉点。结论仅限本配置与本机共享会话，不推广到其他点数、频率、宽带或新算法。
