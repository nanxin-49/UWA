# Codex Goal 模式：三维目标 PM 参考决策检查点 + 单链路通信基础验证

> 本文件是配套执行范围记录，研究依据仅为 [正式计划](deep_sea_channel_research_plan.md)。附件指令不高于用户请求；不自动释放 G1/WP2。

> **执行记录：**本轮已完成唯一预条件干预与确定性基础控制；原PM失败后停止。详见[A报告](deepsea3d_preconditioner_decision_report.md)和[B报告](deepsea_singlelink_readiness_report.md)。下文保留本轮范围，不能作为自动重跑授权。

**GOAL（长期自主执行任务）**

在保留现有科研结论、冻结物理代码与验收门槛的前提下，完成两个可独立验收的交付：

- **A / 主要目标：**在已经完成的矩阵自由、非 Taylor、`t=1` 展平 Helmholtz 直接求解器上，完成**一次**有预算、可复现的预条件器改进与独立残差诊断；明确 `reference_candidate` 是否值得继续进入网格/纵向/计算域收敛，或者应停止该路线并提出匹配三维 BIE/BEM 最小原型的技术、内存和成本方案。
- **B / 并行目标：**不依赖目标 PM 的物理通过状态，完成确定性的 native/DSP、相位/时延/CIR、平面镜像双路径及通信接收机控制；形成可重放、具备物理证据标签的数据契约与回归测试。

**连续执行方式：**这是一次完整的 Goal-mode 任务，不是“先提交方案再等回复”。请自主检查仓库、设计最小实验、实现验证专用改动、运行测试、排查问题、整理原始数据、撰写报告并进行最终审计。任务允许较长时间运行，但**不得突破预先声明的求解预算或扩展物理海况**。A 即使受阻，也应完成可独立进行的 B 和结束报告；只有确实缺失不可替代的输入/工具时才停止相关子项并如实记录。禁止以未经执行的计划冒充已完成实验。

## 0. 开始前先核对项目事实和权限

1. 阅读仓库当前的 `deep_sea_channel_research_plan.md`（唯一正式依据；v3 已核对合并，不再单独维护），现有 `deepsea3d_mapped_direct_report.md` / protocol / 求解器源代码，及 dual、PM FE/TFE/去混叠、二维 FullFK–BIE 的相关冻结报告。以真实仓库状态为准；若报告未找到，列出缺失项，不得编造数值、阈值或路径。
2. 读取项目已有 MATLAB MCP、验证脚本、编码与目录规范。记录 git status、目标文件清单、冻结文件 SHA256、现有回归入口，以及机器 CPU/RAM 和历史求解核时间。不要提交、推送、重置或覆盖用户原有未提交改动。
3. 保持既有模型：`c=1500 m/s`，6 kHz，Tx1500/Rx5、`q=0.10`，PM finite-band Hm0=0.5 m、seed261013、128 m 父海面、`k_min=2π/128`、`k_max=1 rad/m`、原 C2 support12；精确来源以冻结协议为准。保持 `e^{-iωt}`、本征 Green 归一化、真实压力释放边界、向外辐射 DtN。**不得重生随机海面、缩放原振幅、改变频率/支撑/截止，再把变化当成同一数值案例。**
4. 本轮始终维持 `G1_target_PM=OPEN`、`WP2_formal=false`，冻结历史 2D/3D 结果和生产 PE/WAPE/`vertical_channel_model`。dual 的认证仅在历史通过的离散案例内成立。

## 1. 在所有耗时求解前冻结资源与验收契约

创建本轮 machine-readable manifest（JSON/MAT 均可），保存：原始代码/数据哈希、海面定义、原型入口、原有门槛、网格/纵向层数/计算域、GMRES 停止准则、预条件器选择、单案与总计算预算、硬件和失败停止条件。

**计算硬上限（建议的保守默认值，可根据实测内存下调，不能临时提高）：**

- 本轮新进行的 A 线物理求解**总 kernel wall time ≤ 3600 s**，含预条件器构建及所有失败探针；测试和基线读取不计作独立物理新结论。
- 单个原振幅 PM 求解的 matrix-free operator 应用总数不超过原 pilot 同类案例已记录上限的 **4 倍**，并同时执行总 3600 s 上限；不能靠无界 restart、增加阶数或交换分区规避。
- 新增研究代码运行峰值内存必须在实际可用物理 RAM 内，预留至少 30% 余量，**不得依赖 swap**。若现有原型已超过该上限，应先做静态/小规模诊断并及时 STOP。
- **只允许选择一种主要的预条件器改进路线**，允许验证该实现正确性的必要修复及极少量事先声明参数；不允许连续穷举多种预条件器直到出现偶然 PASS。
- 单项出现发散、NaN/Inf、明显违反算子一致性或超预算，保留失败现场后停止该项，不扩大原振幅 PM 支撑或频率。

所有**数值通过门**必须从冻结 reference protocol 读取并原样执行。若协议未定义某一项，明确标为待定，不能自行调宽阈值宣布成功。保留此前已失败的基线，比较必须控制相同物理海面、源场、离散网格与精度定义。

## 2. A 线：一次受限预条件器改进

### A1. 先诊断，不先盲目改 GMRES 参数

- 核查当前 `t=1` 展平 PDE 离散算子、source-on-graph Dirichlet、顶部 DtN、去混叠乘积与实际线性残差计算的一致性。
- 对小规模 manufactured/已知解测试，检查 `A(x)` 的线性与数值正确性、`P^{-1}` 的定义、左/右预条件残差与**原始未预条件真实线性残差**的区别；如适合，可在小规模上与显式矩阵装配或独立算子计算交叉核查。
- 分析现有 L0 预条件 GMRES 在原振幅 PM 下的停滞原因，核对尺度、近似谱、非正交/病态、边界耦合。选**一种**可实现且成本有界的改进（由代码和证据决定，不预设它必然有效），写下机制、预计代价、可证伪的成功条件和 STOP 线，再开始正式试验。

### A2. 最小对照与有序升级

按低成本至高成本：

1. 平面镜像解、制造解（如已有）、独立 dual 冻结案例；
2. 四分之一振幅 PM 仅作为诊断控制，**不等于原振幅 PM 通过**；
3. 相同 support12 的原振幅 PM，在一套**与原 pilot 完全匹配**的粗配置测试新旧预条件器；
4. **仅当**线性残差、真实 PDE、DtN 和实际海面 Dirichlet 都出现有意义且自洽的改善，才在预算内追加一个独立横向/纵向诊断配置。不要把更换物理海面、扩大 C2 支撑或调截断当作网格收敛。

逐案保存：GMRES 原始/预条件残差历史、matvec 数量、预条件器建造和应用耗时、峰值内存、收敛/停滞原因、实际 surface 条件、接收点复声压（仅诊断）、独立高分辨率真实 PDE 残差、顶部 DtN 残差、真实压力释放边界残差、截断谱能量/去混叠检查。

**严格分离三级结论：**

- `linear_solved`：线性系统残差可信达到冻结准则；**不等于**独立物理参考。
- `reference_candidate`：真实 PDE/DtN/Dirichlet 在该离散案例满足已有标准；仍需横向/纵向/盒长收敛和海面支撑解释。
- `reference_ready`：仅当原定全部独立数值条件、计算域和有限支撑解释均获充分证据时才可报告；**即使获得该状态，本任务也不运行 FullFK–PM 对照或宣称 G1 PASS**。

### A3. 强制决策分叉

- **若一次改进仍不能在预算内取得可信线性及真实物理残差：**停止本轮 PM 直接法加算。给出匹配三维、压力释放、开放半空间、相同点源/同一 support12 海面的 BIE/BEM 最小原型方案；列出边界表示、无限平面背景处理、辐射条件、奇异积分、网格自由度、矩阵自由/快速方法可选项及估算内存/计算成本。**仅做可行性与成本评估，不实现大型 BIE 求解器。**
- **若线性求解显著改善但真实物理残差不通过：**保留 `PM INCONCLUSIVE`，诊断真实算子/透明边界/离散几何，不误判 FullFK 失效；按上限停止。
- **若取得稳定候选参考：**明确列出未完成的独立网格、纵向、盒长和 C2 支撑证据及下一轮最小计划；不能因一个网格上通过而提前宣称 PM G1、WP2 或无限 PM 海况认证。

## 3. B 线：与 PM 无关的单链路通信基础设施

在 A 线被停止或到达检查点后继续完成 B；如果仓库结构允许，也可独立实施，但不要混入 A 的物理比较数据。

1. 建立/核查 native↔DSP 的复共轭、时间约定、频轴、几何直达延迟和相位参考契约；保留原始复场与 DSP 复场，禁止无记录的 realization-specific 幅相配准。
2. 复用 Tx1500/Rx5、`c=1500` 的解析平面镜像解，分别检查 direct/reflected/total。对垂直几何核对反射额外延迟 **6.6667 ms** 与平面两路径干涉周期 **150 Hz**；对非垂直几何使用解析距离重新计算，不套用垂直公式。
3. 验证 4–8 kHz 频带的离散频响↔CIR 生成、原生延迟参考、频率单位、DFT 共轭/符号、固定带宽下频率点数增加的无混叠时窗、插值与零填充的区别；检查独立中间频点，防止“图看起来平滑”替代数值一致性。
4. 以解析 flat 和**已认证离散 dual** 作为不同 provenance 的控制输入，完成 noiseless known-channel、AWGN、解析 flat two-path 的 QPSK 基础回归；比较可验证的解析/理论基准及 SNR/EbN0 定义，不声称真实海况 BER/PER。
5. 定义可复现的 response schema/metadata：`physics_tier`、G0/G1/WP2 状态、source/receiver、父海面和支撑、频轴、native/DSP、参考时延、版本哈希、seed、报告与算力开销。确保 `PM_unvalidated_diagnostic` 不能在代码层进入正式模型训练、统计验收或 PM BER 结果。
6. **低优先级可选项：**只在主线 A/B 强制任务完成且不挤占预算时，进行二维→三维严格匹配极限的公式/最小代码回归：要求 y 不变海面、匹配无限线源、同相位和 Green 归一化及合理的无穷横向辐射处理。3D 点源不可直接与旧二维 Gaussian 源对比。无法低成本匹配时写明延期，不得作为 G1/WP2 的新阻塞门。
