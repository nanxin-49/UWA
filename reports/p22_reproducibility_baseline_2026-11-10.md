## 共同窗到底修好了什么

65、129、257 点保存频率都覆盖 4000–8000 Hz，步距分别为 62.5、31.25、15.625 Hz，严格嵌套。带末点用于插值，IFFT 用前 256 点，得到 0.25 ms 采样、64 ms 周期窗。直达和反射使用共同 DSP 原点 `97/1500 = 0.0646666666666667 s`；反射额外时延为 `6/1500 = 4 ms`。

具体做法是先给反射乘 `exp(+i 2π f·0.004)`，把主要线性延迟相位去掉，再对直达与反射包络分别做复线性插值，最后把反射延迟放回。这样是在同一时间表示中比较三个网格，未逐路径移动峰值，也未调节原 `1e-3` 门。

| 本轮重算指标 | 最大值 | 原门 |
|---|---:|---:|
| 65 对 129 共同窗 CIR 相对差 | `7.1033e-6` | `1e-3` |
| 65 对独立保存 257 点 CIR 相对差 | `8.2248e-6` | `1e-3` |
| 129 对独立保存 257 点 CIR 相对差 | `3.0923e-6` | `1e-3` |
| `[-4,12) ms` 外能量比例 | `1.5103e-5` | `1e-3` |
| CSV 与 MAT 的 CIR 最大绝对差 | `5.6644e-16` | `1e-13` |
| 保存频响分量闭合最大绝对差 | `3.1032e-17` | `1e-12`（额外一致性检查） |

这说明既有 PE 频响在这套共同表示中相容，可以作为后续受控通信的输入。它没有使原始 16/32 ms 窗口比较变成通过：旧相对差约 `0.043875` 和原失败检查点保留不动，也没有新增物理传播证据。

## QPSK 结果说明什么

沿用原配置：4 ksymbol/s，QPSK Gray 映射，256 tap，块长 512，CP 255，同一因果保护移位 16 sample；每个 SNR 262144 bit / 256 frame，SNR 为 0/6/12/18/24 dB。比特种子 61030，噪声种子 `62030+100*k`，两种海面配对使用同一噪声种子。SNR 定义在信道后、均衡前，不能直接改写成 `Eb/N0`。

审计重放 `y=filter(h,1,tx_cp)` 和 `W=conj(H)/(|H|²+noise_power)`，未重新生成比特或更换信道、SNR、种子。均衡符号与原 MAT 最大绝对差为 0，误比特逐项一致；CSV 指标最大绝对差 `3.9080e-14`，小于原 `1e-12` 门。两种海面的原无噪声控制均为 0 误比特。

例如，保存的平面 BER 从 0 dB 的约 0.199 降至 24 dB 的 `3/262144 ≈ 1.14e-5`；24 dB 的 PER 为 `2/256 = 0.0078125`。这表明既有链路随噪声减小出现合理改善，并能确定性重放。24 dB 仍有 3 个误比特，不能写“高信噪比零误码”。平面与原弱正弦曲线几乎重合，只支持这个弱扰动、单接收点、已知 CSI 配置；不支持“粗糙海面对通信普遍无影响”。

## 两频点复核的范围与局限

4062.5/4031.25 Hz 的五层 BIE 参考相对敏感性分别为 `4.7803721e-8`、`5.5508811e-8`，低于原 `1e-4` 经验参考门；冻结插值预测在 4031.25 Hz 的复相对误差为 `2.7741818e-7`。这些数字与历史审计一致。

FullFK/BIE 相对差分别约 `4.0561e-8`、`3.5432e-8`，都没有超过五倍合并经验分辨率，因此本轮比较分不清更细的模型差，不能判定模型相等或谁更准确。PE/BIE 保存差约 `2.0805e-7`、`4.8436e-7`；4031.25 Hz 缺独立 PE 步长/网格敏感性，不能给它一个模型分辨通过结论。

两频点采用的是九点冻结全局参考 `96.875/1500 = 0.0645833333333333 s`，比 PE 控制实验的原点早 `0.0833333 ms`。两个成果包各自内部的共同原点一致，但跨包拼接频响或 CIR 前必须显式转换参考，不能直接拼。

本轮新审计未重演历史 Python 的全部检查：没有从冻结源重新合成入射场、没有逐元素验证全部边界数组，也没有把预测先后顺序变成新的独立时钟见证。原 MATLAB 作业退出码、耗时、预测冻结状态和日志仍作为历史证据保存；本轮通过主要数值量重算与清单完整性增加可信度，不把它描述成旧审计的全覆盖替代。
