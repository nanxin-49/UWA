# Strict-normal approximation applicability: execution plan

## Frozen physics and conventions

- 4 kHz, c=1500 m/s, Tx/Rx path 100+3 m, 1-transverse PE.
- X-source coherent Bellhop, 10,001 beams, the existing receiver map and
  conjugation convention.
- The accepted half-plane Helmholtz BIE formulation and discretization.
- The same C2-tapered surfaces and receiver grid used by the current BIE Goal.
- Only the Gaussian source width changes. No amplitude/phase fit is allowed.

## Cases

1. Primary low-slope scan: `A=0.05 m`, `K=0.10 rad/m`,
   `sigma=[0.3,0.5,1,2] m`.
2. Optional `sigma=4 m` only if the mandatory scan passes footprint, window,
   BIE residual, source-pattern sampling, and finite-field checks.
3. High-K discriminator: `A=0.02 m`, `K=0.47 rad/m`, initially at
   `sigma=0.3` and `2 m`.
4. Strong-height discriminator: `A=0.20 m`, `K=0.10 rad/m`, at
   `sigma=0.3` and `2 m`; the sigma=0.3 point reuses authoritative R5.

The sigma=0.3 entries reuse the authoritative R4/G0 Bellhop and BIE fields;
all PE Model-0/Model-1 fields are regenerated by the current validation-only
helper. Every new sigma gets a newly generated analytic Gaussian `.sbp` using
the unchanged formula, not a refit.

## Recorded quantities

- Actual discrete-spectrum `theta_rms`, `theta_95`, `theta_99`, `<kz>/k`, and
  `1-<cos(theta)>`.
- AS/BIE flat-field 95/99% receiver footprint, surface-incident outer-window
  energy, BIE boundary/linear residual, Bellhop wall/phase/p-q/range guards.
- Model-0, kz-aware Model-1, and Bellhop errors against BIE:
  `E_G`, phase RMS, TL RMS, `rho_shape`, and `E_aligned`.
- Model-0/Model-1 convergence and the dependence of the angle-specific excess
  error on `theta_rms^2` and `1-<cos(theta)>`.

## Gates and interpretation

Numerical gates precede physical interpretation. The 99% footprint must stay
inside the untapered `|x|<=42 m` surface region, edge energy must remain below
`1e-5`, BIE residuals must remain at the accepted reference level, Bellhop
geometry must pass, and all fields must be finite.

The Bellhop fan retains the established `+/-30 deg` cap. For narrower sources,
the fan is reduced only where the analytic Gaussian directivity drops below
the validation binary's `0.005` ray-amplitude termination threshold (a
conservative `0.006` cutoff is used). The omitted analytic angular power is
reported and must remain below `5e-4`; the historical `sigma=0.3 m` case is the
limiting value (`3.23e-4`), while the adaptive cases omit about `6e-6`.

For a practical deep-water applicability statement, the existing controlled
Region-I limits are retained as engineering thresholds:

```text
E_G <= 0.0108994
phase RMS <= 0.0108992 rad
TL RMS <= 0.0107979 dB
rho_shape >= 0.9995
```

Classification:

- `STRICT_NORMAL_APPROXIMATION_VALIDATED`: low-K errors contract with the
  angular spectrum, Model-0 and Model-1 merge, the accepted angle range passes
  the Region-I thresholds, and high-K leaves no material residual.
- `STRICT_NORMAL_APPROXIMATION_PARTIAL`: the finite-angle mechanism and a
  useful low-K angle range are established, but high-K or another metric keeps
  a separate residual.
- `STRICT_NORMAL_APPROXIMATION_NOT_DOMINANT`: narrowing the angle spectrum does
  not systematically reduce Model-0/BIE error or merge Model-0 with Model-1.

The mandatory scan is completed before deciding whether sigma=4 m adds useful
information. Fixed PM and production PE changes remain out of scope.
