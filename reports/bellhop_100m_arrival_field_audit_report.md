# Bellhop C 场与 ARR 重建诊断

## 目的

本次小诊断固定100 m物理水深、89.5°、4 kHz、10001条波束和同一确定性粗糙海面，只比较已经完成的 `epsilon=10^-4 m` 与 `10^-5 m` 两个案例。Bellhop `C` 模式直接输出相干声场；`A` 模式的ASCII `.arr`由独立脚本重建。目的不是重新验收Bellhop或PE，而是判断前一轮粗糙面高阶路径变化是否由 ARR 表示层单独制造。

没有运行PE、没有修改PE/Bellhop核心、没有修改生产参数，也没有扩大角度或频率扫描。

## 相位约定与读取

安装版本 `influence.f90` 的相干表达式为

```text
U_native = sum A * exp(i*phase - i*omega*delay)
```

因此 C 场和 ARR 合成都取一次共轭，统一为项目采用的 `exp(-i omega t)`。没有逐点拟合 C/ARR 绝对幅度，只比较两个 epsilon 之间的复比值。C输出的SHD使用固定长度记录：第8条是距离记录，第9条开始是接收深度的复压力；本脚本独立读取该布局，不修改公共SHD读取器。

ARR 仍受安装版本的单精度 `REAL/COMPLEX` 存储和相邻贡献合并规则影响，记录数变化本身不等于物理 eigenray 的出现或消失。

## 结论

C场和ARR重建对 epsilon 的变化几乎一致：幅度比仅相差约0.006%，相位变化只相差 `2.29e-5 rad`，等效TL差为 `0.000533 dB`。因此，前一轮粗糙面高阶含底类别的敏感性**不是由ARR重建单独制造的**，而是已经存在于Bellhop的相干场/近底几何计算中；ARR的单精度和合并规则会改变个别弱类别的记录细节，但不能解释主导变化。

这也不代表粗糙面高阶路径已经物理收敛。此前 `top/bottom=2/1` 等类别仍然超过离底极限门槛，完整多途检查应继续保持未通过状态。下一步如果继续，只应针对一个粗糙面案例检查少量波束/轨迹以及 `C` 模式场，不能直接扩大角度、频率或用默认 sponge 掩盖问题。
