# BLACK 信道：下载、基础复现与特征分析

本报告只使用 BLACK 及其配套噪声。复现状态：**PASS**。

- 本次结果目录：`E:/MISC/CARPE3D_matlab/Explain/results/validation/black_channel_basics/runs/20261016_175145_949`。
- 实际载频 18000 Hz；时延轴 25000 Hz；快照 125 Hz；记录 36.552 s；8 个接收阵元。

数据是海试估计的等效复基带信道，不是原始录音；幅度经过归一化。本报告不据此推断绝对传播损失，不将相对时延解释为绝对传播时间。

## 复现与检查

采用官方 `unpack`、`replay`、`noisegen`，不修改其算法。解包仅展示幅度，以原生快照率输出；已从绘图坐标中扣除左补零长度，补零按实际漂移范围检查并增加（左/右比例 0.1000/0.1000）。复现参数为 8192 个 BPSK 符号、6.25 ksym/s、100 kHz 通带采样率、首尾 20 ms 静默、记录四分之一处起始，随机种子 1994/twister。

- 文件：两文件大小与官方 MD5 一致，另记录 SHA-256；HDF5 类型检查通过后加载。
- 合成双径控制：理论均值 0.8 ms、RMS 1.6 ms；负相位斜率与 Welch 频率轴检查通过。
- 同一输入重复回放相对误差：`0`（门限 1e-12）。
- 配套噪声生成并缩放后的整体 SNR：20.00000000 dB（目标 20 dB，包含静默和尾段）。
- 8 阵元主到达最大误差：0.103957 个时延采样点（门限 2 点，80.0 us）；检查结果 1。

到达检查使用无噪声回放的八段非相干匹配滤波，与保存抽头主峰和平均相位时延漂移作比较。此检查验证重建/回放一致性，不等同于重新估计原始海试信道。

## 基本多普勒

![BLACK 基本多普勒](../results/validation/black_channel_basics/runs/20261016_175145_949/black_03_doppler.png)

图 3 上图使用 `phi_hat` 的连续相位，每 0.1 s 独立拟合斜率，按 `f_D = (d phi / dt)/(2 pi)` 定义符号；包含 `f_resamp`（若存在）的固定频移贡献 0.000000 Hz。全部阵元与时段的公共频移范围为 **-5.7801–5.4651 Hz**。

下图每阵元选取平均能量最大的固定抽头，原生快照率计算 Welch 谱：4 s periodic Hann 窗、50% 重叠、无额外零填充，频率栅格 0.250 Hz，奈奎斯特范围 +/- 62.5 Hz。右图仅为同一谱的 +/-5 Hz 放大。谱逐阵元峰值归一化，标记为**残余抽头谱**；不得将其宽度当作完整信道多普勒扩展。窄峰宽度含有限时窗效应，不据此宣称非零物理扩展；未增加复杂展宽拟合。

本次三个代表阵元的公共频移曲线接近，并随时间平滑改变正负；保存主抽头的残余谱则集中在零频附近。两者共同说明：移除的公共相位变化不能忽略，仅看保存抽头的窄谱会遗漏这部分时变频移。
