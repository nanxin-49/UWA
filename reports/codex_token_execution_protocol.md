## 按需加载与恢复

1. 首次只看 `PROJECT_CONTEXT.md` 顶部当前状态、被授权计划顶部修订及对应阶段条款、必要入口的签名/导航；先用精确路径或 `rg -n` 定位。所有仓库搜索排除 `cash/`。记录已检查文件的 SHA-256 或版本及相关行段。
2. 只有结论、接口、配置或失败诊断明确依赖时，才读取历史报告/代码/日志的相关段。已确认未变化的材料只引用路径和版本；若文件版本变化，再读受影响段。
3. 恢复时先读最新作业检查点和当轮授权，再核输入/代码/审计证据哈希及真实状态。`COMPLETE` 但证据不全、哈希不符、参考资格失效或审计未运行，不可复用其 PASS；只重新验证受影响的步骤及下游。失败快照与旧日志保留。

## 作业目录与两种输出

每个被授权作业使用唯一 `results/<category>/<case>/<run_id>/<job_id>/`，不得覆盖旧 run。完整 `stdout.log`、`stderr.log`（本地 MCP 内使用可控 `diary` 时记录 diary 路径）、真实 `exit_code`、配置、输入/代码与输出 SHA-256、资源前后测量、审计原始结果保存在该目录或已登记的子目录。远端 SSH 只使用原计划允许的非交互、真实退出码与资源门；本地只用现有 MATLAB MCP 会话。MATLAB MCP 输出若不能完整持久化，记录该限制，不能凭截断输出宣称完成。

作业完成后生成机器可读 `checkpoint.json`，并只把以下短回执送回模型（示意字段，数值仅作格式例子）：

```json
{"run_id":"<id>","job_id":"<id>","status":"COMPLETE|FAILED|BLOCKED|INCONCLUSIVE","elapsed_s":12.3,"metrics":{"<name_with_unit>":0.0},"failed_checks":0,"result_dir":"<absolute path>","stdout_log":"<absolute path>","stderr_log":"<absolute path>","audit_path":"<absolute path or null>","checkpoint_path":"<absolute path>"}
```

短回执的 `metrics` 只放当前门所需的少量有名称、有单位数值；完整指标表仍保存为 CSV/MAT/JSON。`status=COMPLETE` 仅表示列明的作业步骤完成；数值或物理资格必须由对应独立审计及阶段门明确给出。`failed_checks` 含失败与未执行必需检查的分类，不能把未运行写成零失败。失败时先按错误关键字与行号读取 `stderr.log` 或 diary 的相关小片段，再按具体诊断需要扩展；保留原文件，不向模型展开整份长日志。

`checkpoint.json` 至少记录 `completed_steps`、`status`、`config`（含随机种子/容差/物理单位）、`input_versions_sha256`、`code_versions_sha256`、`artifacts_sha256`、`failed_or_unrun_checks`、`resource_usage`（RAM、CPU、磁盘和累计/单作业耗时及预算）、`audit_status_and_path`、`next_allowed_step`、`execution_mode`、`matlab_release`。对未取得的信息写 `unknown`，不伪填哈希或 PASS。作业和阶段边界都写检查点；阶段检查点汇总其作业路径和剩余门，不复制长日志。

## 自动核验与独立审计

- 数值比较由 MATLAB 或确定性脚本按冻结支持、权重、分母和容差计算，保存最大/相对差、失败索引及原始结果。MAT/CSV 对照、SHA-256 清单、FIG/PNG 从保存源独立重绘等沿用对应阶段已定义的审计入口，不以文件存在或相同脚本自报成功代替独立检查。
- 未变化产物可复用的条件是输入与代码版本、配置、产物 SHA、原审计状态、适用支持与门槛均有效；任一项变化时列出受影响项并重新运行必要审计。跨平台求解资格等未闭合问题继续保持受限，不因输出压缩升级状态。
- 保存审计入口、运行方式、实际执行时间、退出/异常、完整结果与失败数。短回执只是索引；研究报告继续给出必要的数值证据、限制及可复现路径。

## 可比较的测量

对相同的授权任务、相同输入版本与验证门，分别记录旧流程与本协议流程的：模型收到的工具输出字节数/可得的 token 数、重复读取的文件或哈希次数、工具调用数、被截断输出次数、完整日志字节数、真正执行的独立审计数、失败/未运行门数和最终产物 SHA 清单。测量窗口从首次状态读取到阶段回执；分别计入首次、恢复和失败诊断场景。若无法取得真实 token 用量，就只报告输出字节与调用次数，不换算节省百分比。比较资格以审计覆盖和结果一致为先决条件；少执行了必需审计的样本不能算优化成功。
