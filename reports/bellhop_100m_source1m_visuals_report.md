# 100 m 水深、实际离底1 m：Bellhop代表案例与声线图

## 任务目标与本轮结论

用户接受把发射机实际安装位置改为离底1 m，因此本轮停止微小epsilon的边界极限研究，采用水深100 m、Tx深度99 m、Rx深度3 m继续正常坐标Bellhop展示。这是真实几何变化，不是离底0 m的数值近似；未修改PE生产默认配置。

已完成一个4 kHz、89.5°代表几何：193条A模式arrival、199条E接收贡献记录、167个独立R发射角重建，以及1001条R展示扇区。两类PNG均已保存并检查。没有补齐10角度扫描、4–8 kHz宽带或重新验证PE。

## 1. 实际设置

| 参数 | 设置 |
|---|---|
| 物理坐标 | 平均海面z=0，正深度向下，平海底z=100 m |
| Tx | x=0，z=99 m，实际离底1 m，无epsilon |
| Rx | z=3 m，x=0.8377793079 m |
| 几何角 | Tx–Rx连线与水平夹角89.5°，不是每条声线的发射角 |
| 水体 | 均匀1500 m/s、1 g/cm³，无水体吸收 |
| 海底 | 流体半空间：1800 m/s、2 g/cm³、0.5 dB/波长、剪切速度0 |
| 海面 | 同一三余弦一维粗糙深度剖面，压力释放 |
| 声源 | 单位幅度Cartesian line source X，仅本次规定的向上角扇区 |
| 发射扇区 | [-89.9999,-60]°；A/E为10001波束，展示R为1001条 |
| 步长和海面采样 | 射线步长0.02 m，剖面间隔0.01 m |
| 接收计算范围 | A/E及其独立R重建：水平±12 m |
| 展示扇区范围 | 单独R：水平±120 m，不在首次触面处剪断 |

固定海面物理深度（单位m，正号向下）：

`eta(x)=0.045*cos(2*pi*x/6+0.30)+0.020*cos(2*pi*x/2.2-1.10)+0.010*cos(2*pi*x/0.9+2.00)`。

各输入使用相同公式，覆盖各自范围内的负距离，不重新归一化。120 m展示范围使较倾斜声线也能触面并显示回程。不能把12 m接收结果称为120 m范围的多途全集，也没有验证范围外返回贡献收敛。最初统一120 m的A试跑因长多次反射耗时及存储警告中止，没有作为正式接收结果。

输入整体下移1 m：Tx=100 m、Rx=4 m、BTY海底=101 m、海面=1+eta。声速表到101.1 m，实际反射边界仍由BTY固定在101 m。绘图减去这一偏移，海底100 m、Tx99 m，没有500 m海底。底质是可复现测试假设，不是实测底质；X线源不是生产PE Gaussian或实测换能器，本轮不比较PE/Bellhop绝对幅度。

**E贡献波束不一定精确穿过点接收机。** 在所画前缀上，最大到Rx最近距离10.0569 m，108条大于1 m、8条不大于0.1 m；最大E终点到Rx距离96.4545 m。指标量的是已写出的贡献前缀/终点，不是无限延长中心线的垂距。较远的高阶贡献保留显示，但没有被确认成物理有效的精确命中路径。若要求精确命中Rx的全部几何声线，需要专门的eigenray求解；不能把199当作真实独立到达路径数。

## 3. 完整发射扇区和终止限制

1001/1001条R记录全部绘制；1001条经历海面反射，961条经历海底反射。最大物理深度100 m，横向约-120..120 m。颜色按整条保存轨迹的最终反射历史分类，不是逐段反射次数，也不是声强。1001是展示发射角采样数，不是文件固有上限。

接收A、E、独立重建R均无轨迹存储警告。120 m展示扇区有**33条声线达到内部轨迹存储上限**，按实际保存终点绘制。Bellhop也会在出界、振幅过小等条件下终止。这里的完整指全部已计算并保存的记录/顶点，不代表无穷多次反射算完。WriteRay本身也会压缩长轨迹的顶点；绘图没有额外首次触面截断，没有补画未计算的路径。

## 5. 实现、检查与下一步

新增 `scripts/reporting/generate_bellhop_100m_source1m_visuals_vertical.m`，复用保留源码的ARR/RAY读取和前缀重建方法。没有读取cash、修改PE/Gaussian/反射公式/通信链或生产默认值。MATLAB正常退出0、checkcode无问题，两张PNG已逐张检查深度和标记；主文档和脚本索引同步更新。按本轮范围不运行无关PE/通信回归或追加收敛矩阵。

从仓库根目录运行，本轮无overrides：

```matlab
addpath('scripts/reporting')
generate_bellhop_100m_source1m_visuals_vertical();
```

仅重绘，不重算Bellhop：

```matlab
generate_bellhop_100m_source1m_visuals_vertical(struct('render_only',true));
```

离底1 m方案已用于代表展示，无需继续微小epsilon检查。但本轮没有证明粗糙面多途幅相收敛或89.5°等价于90°。若继续近垂直比较，可保持此安装与海面，仅补少量角度并分开查看直达、一次海面和含底类别；须区分波束相干响应与精确eigenray。
