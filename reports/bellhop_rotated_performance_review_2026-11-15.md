# Bellhop旋转模型性能审查与平面墙安全加速（2026-11-15）

结论：当前实际构建确有全线段扫描，但本例墙只有2段。独立overlay采用保守排除与跳过无效几何查询，保持原精确求交公式、段顺序和反射实现。第13阶101束3列的数值结果逐字节不变；无采样的一对耗时由2.4268952s降至2.1920121s，实测1.10715倍、耗时减少9.678%。第二对计时在1.5GiB RAM启动门停止，未补齐原计划3对；加速结论仅是一次配对观测。完整A及其他组继续暂停，本轮不提交、不推送。

## 六个问题的直接回答

1. **最耗时的环节是什么？** 当前最小例是射线追踪/步进和Q型声速查询。粗粒度计时TraceRay2D合计2.020559s，InfluenceGeoHatCart合计0.1305854s，ScalePressure合计0.00152s。前者约占带采样进程2.7167923s的74.4%；后两者约4.81%和0.056%。这包含操作系统调度、插桩和运行环境，不能用该余量直接宣称输出I/O占20.7%。
2. **求交是否全线段穷举？** 是。实际已接受REAL8构建中的WallCrossingStep每次遍历2段，GetWallGeometry也遍历2段；每个Step2D两次ReduceStep2D，墙激活时各调用一次WallCrossingStep；每步无条件查询一次GetWallGeometry，每次真实反射后主程序额外查询一次。一次101束积分共12193259步、24386518次ReduceStep2D、22698226次求交、12194572次几何查询。
3. **穷举占总时间多少？** 本轮没有取得可信的精确比例。1/1024低频时钟采样外推，两扫描函数扣除空时钟开销后约0.65848s，约占带采样进程24.24%；未经扣除约1.39576s、51.38%。这两个值不是置信区间：短函数、100ns时钟量化、系统性采样和插桩扰动造成显著偏差，外推Step2D总时间甚至超过TraceRay2D粗粒度实测，因此不将其作为精确归因。实际无采样加速由独立配对计时给出，不能声称去掉扫描会省去一半运行时间。
4. **最值得实施什么？** 对本例精确竖直平面先做保守范围排除，只在步段接近平面时执行原始精确公式；只在墙激活且终点接近平面时查询几何。当前两段不值得建设BVH。一般曲线仍保留全扫描。预计算段几何或复用反射命中索引均可考虑，但优化后只剩5252次段检查，继续优化收益很小。
5. **实际加速多少？** 无采样配对实测1.10715倍，耗时减少9.678%；进程CPU采样2.234375→1.890625s，减少15.385%。另一次优化版1.9874675s未获得配对原版，单列保存，不用于抬高加速比例。不能由一次配对推算完整A或201列的固定加速比例。
6. **能否安全恢复A？** 当前不恢复。最小案例的优化数值合同通过，可作为后续人工审查候选；未取得完整A、其他阶数/组的新增资格，重复计时还触发RAM门，当前调度停止门及未采用旧草稿也未整合。恢复必须另经人工审查，继续原预算累计与资源门，核验旧分量和输入SHA，不能把本报告当作计算许可。

## 重复工作与方案选择

原ConfigureWallProfile已预计算单位段切向、段长、节点切向和曲率；但两个扫描函数仍逐次重算d=WallX(i+1)-WallX(i)，GetWallGeometry重复求dot(d,d)，各调用还重算q、交积、投影和参数位置。每一步两次求交使用不同的中点方向，**不能直接复用第一次hWall**。原Step2D末端查询用于判WallHit，而主程序会先将命中r闭合到精确墙面，再查询几何供Reflect2D使用，**不能直接用闭合前残差代替闭合后的残差**。

| 方案 | 本轮判断 |
|---|---|
| 平面直接解析根 | 适合作保守排除。未用解析根替换原hCand，以避免改变运算次序、容差和共享节点段归属。 |
| 单调参数二分 | 对长单调曲线有价值；当前仅2段不值得。一般参数曲线可能在r上折返，不能盲按r二分。当前Q声速表已用缓存当前格+FastQSearch二分，激活侧文件中fast_q=1，没有另一次全表穷举。 |
| AABB/BVH/空间分区 | 对大规模一般曲线才有意义；本例构建/查询成本大于2段扫描，未实施。 |
| 预计算段d、d² | 原实现可进一步缓存，算式也易保持；本轮经排除后仅5252次检查，剩余收益低，未额外增加状态/失效维护。 |
| 复用命中段索引 | 主程序重复1313次反射几何查询，优化后只占2626次几何查询的一半；保留原查询以维持墙面闭合与段节点tie规则。今后可缓存候选索引并重新计算参数，但不值得本轮复杂化。 |

## 实施的独立优化

只修改独立optimized_plain_overlay01/Step.f90；其余7个Fortran模块与原REAL8 overlay逐字节相同。源码差分见[flatwall_optimization_review.patch](../results/validation/bellhop_rotated_fig12b/20261115_performance_review_01/flatwall_optimization_review.patch)。

- ConfigureWallProfile用ALL(R==R(1))识别**精确竖直平面**，不以拟合或倾角容差把曲线当平面。
- WallCrossingStep中，如果试探直线段的整个r包围区间在墙面1e-7m保守厚层以外，直接返回原HUGE无交点；否则继续原两段完整循环。1e-7只用于扩大保留区，未改变原1e-10正向/参数门或1e-8墙根闭合门，未更改hCand/lam公式、MIN及遍历顺序。
- Step2D在WallActive=false时不查询无效墙。在当前精确竖直墙情况下，只有abs(r_end-r_wall)<=1e-3m时调用原GetWallGeometry；该层保留原1e-8命中门和1e-3诊断邻域，远处不产生实际命中或诊断。一般曲线激活时仍执行原查询。
- 单精度SHD头、complex32累积/输出及REAL8输入/有效ReceiverRange64/缩放链全部原样保留；本轮没有改散射物理、反射方向公式、p/q、tau、Amp、Phase或步长。

资格限定为当前有限坐标、近单位方向、N=3精确竖直平面和冻结最小例；不将此优化升级为任意尺度、粗糙/折返曲线或其他波束类型的通用资格。
