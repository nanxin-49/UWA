## 2. 物理、相位与源合同

令 `k=2πf/c`，`Ld=|Rx−Tx|`，`L0=|Rx−(xTx,yTx,−zTx)|`，`Lη=|Rx−(xTx,yTx,2η*−zTx)|`，`η*=0.06251088653876558 m` 保持旧锁。原生单位源自由场 `D=exp(ikLd)/(4πLd)`，零高度压力释放像源 `R0=−exp(ikL0)/(4πL0)`，冻结 rough FE 反射为 `R`，`Δ=R−R0`，`H=D+R=D+R0+Δ`，单位 `m⁻¹`。`B*(f)=−exp(ikLη)/(4πLη)` 只分离**已知固定**镜面高度的解析尺度和相位；它不是新的拟合高度，也不代表未知粗糙路径全有镜面时延。保留原生 `R`、`Q=R/B*`、`R0` 和 `D`，否则不能恢复真实总场复相位与绝对时延。

`D,R0,R,H` 是单位源传播 Green 响应。若实际发射信号具有频谱 `S(f)`，接收频谱是按相同傅里叶约定形成的 `Y(f)=H(f)S(f)`；不能把 `S` 当作已含于单位 Green，也不能对每频任意归一、旋相或峰值对齐。当前 4–8 kHz 只有正频带解析响应，实际实声压的负频率需满足相应共轭对称，带外与发射/接收前端仍未指定。

按已有[解析双路径](deepsea_frequency_reconstruction_report.md)和[native/DSP 控制](deepsea_singlelink_readiness_report.md)，`H_abs,DSP(f)=conj(H_native(f))`；相对直达原点 `H_rel,DSP(f)=H_abs,DSP(f) exp(+i2πfτd)`，其中 `τd=Ld/c` 仅由几何给定。各分量使用**同一个**变换和时间原点，`H_rel=D_rel+R_rel`；相对反射相位仍包含 `exp[−i2πf(τr−τd)]`，不得把这部分一并抹掉。绝对 DSP 直达在约 1 s，若误当作 16 ms 周期窗内延迟会混叠；相对 DSP 直达在零。恢复绝对时延须保存 `τd`、载频/频率轴、端点/索引及未经调整的 native 复数。任何逐点整体相位、高度或时移拟合都禁止。

固定总带宽 `B=4000 Hz` 给名义带限时延分辨率 `1/B=0.25 ms`；把 Δf 减半只延长周期窗，不改善这一分辨率。`f_j=4000+jΔf, j=0…N`，`N=32/64/128/256`；两端必须明确保存，DFT/IFFT 只用左闭右开 `j=0…N−1` 的 **N 个独立 bin**，8 kHz 端点作闭合/一致性检查，不重复放入周期序列。令 `fc=6000 Hz`，基带有符号频率 `(j−N/2)Δf`，自然升序为负频到正频；按已验证约定对这一升序数组执行 `ifft(ifftshift(H_rel,DSP))`，时间 `t_n=n/(NΔf)=n/4000`，`n=0…N−1`，幅值归一化与逆 FFT 要在下一轮锁定并核往返。`fc` 的载波相位不能遗漏，端点、shift、共轭与时间原点必须通过解析两路径控制复核。

矩形 4–8 kHz 截断的 sinc 旁瓣、任何预声明窗的主瓣展宽及谱泄漏都改变有限带时域外观；补零只改变显示采样，不增加物理时延分辨率。未知 rough 散射延迟扩展若超过 `16−6.633≈9.367 ms` 的额外余量，65 点周期窗可能混叠；即使 129 点也无无条件保证。**本轮不形成正式 CIR。**现有五锚点间距 1 kHz，已知 `B*` 分离后 `Q` 可稀疏预测，四旧保留点仅给局部支持；65/129 个输出值是同一五个 FE 锚点生成的预测，绝非 65/129 次独立 FE。若预览，逐值标 `PREDICTED_NOT_PHYSICALLY_VALIDATED` 并保留锚点、版本、相位原点和禁止 CIR 验收的元数据。

## 4. 唯一预定重建与下一轮新频点

**建议最小新增四个独立物理点，均在 65 点网格且不与九旧点重合：**常规保留 A=`4750,7250 Hz`，按事前固定的低频和高频两个 1 kHz 锚点区间内的 3/4 与 1/4 位置作覆盖；压力测试 B=`4125,6562.5 Hz`，分别是五锚点 B 在 65 点网格上对相对预测总场 `|Hpred|/|D|` 的两个低值区域代表。解析预览值约 `0.1132/0.1528`，消相指标约 `17.05/12.63`；它们是**预测选点**，不是 FE 事实或无偏样本。旧 5.5 kHz 已显示相消，6.5 kHz 已见可分辨预测偏差；B 组专门探测极值/相消风险。A 的两点用于常规分区检查，不能把四点合并平均作总体结论。若下一轮更关心 5.5 kHz 邻域，可在新增 FE 前用同一冻结规则替换一个压力点并另出协议版本，不能看结果后换点。

## 5. 预测验收与物理参考资格（下一轮协议草案，未执行）

先独立取得 FE 自身资格，再解盲计算逐点 `e_R=|Rpred−RFE|/|RFE|`（严格 `<1e−3` 原筛查），`e_Δ=|Δpred−ΔFE|/|ΔFE|`（非零时），`e_H=|Hpred−HFE|/|HFE|`（非零时），以及 `a_D=|Hpred−HFE|/|D|`。另列 `R,Δ,H` 各自幅度相对误差和未逐点调相的相位差 `arg(pred·conj(FE))`，并比较相邻新旧频点的相位展开、相对直达群时延与解析平面值。近零 `H` 不删样本；若 `e_H` 分母不稳定，同时报告绝对复差和 `a_D`，不将大相对数或小绝对数单独当成通过。新 `e_Δ/e_H/a_D` 或时域门**尚无旧验收阈值**：建议解盲前锁严格 `<1e−3` 的非零 `e_Δ` 与 `a_D` 设计目标、相位/群时延的数值规则及近零判据；若达不到或 FE 分辨不够，就报告受限/STOP，不静默放宽原门。每点另报告 `|Rpred−RFE|/ε_FE`，特别记录 `>5` 的可分辨偏差；`ε_FE` 是同配置变体最大绝对复差，不是严格界。所有逐点最大值和两个组别分别判断，不能只报平均。

参考沿用[原频率协议](deepsea3d_g1_frequency_protocol.md)：真实粗糙边界/离节点、`N/N−2/N−4` 阶数、粗细网格、域、M32/M40 评价尾界及出射/回放/forcing 原门（主要参考量严格 `<1e−4`，回放 `<1e−12`，forcing `<1e−8`）；随后原 FullFK 五配置的非零增量数值差严格 `<1e−3`，FullFK–FE 反射与非零增量物理复误差各 `<1%`。4.5/5.5/6.5/7.5 kHz 的最终 `N=16/20/20/20`；真实边界分别 `1.017e−8/2.358e−10/7.301e−9/1.411e−7`，半网格 `3.093e−7/3.188e−7/3.318e−7/3.715e−7`；网格最大 `9.458e−6`、7.5 kHz 粗 Gauss4 为 `9.892e−4`。5/7 kHz 最终 `N=16/20`，真实边界 `5.703e−8/3.376e−8`，半网格 `3.126e−7/3.375e−7`，网格/域最大 `7.393e−6`，FK 最大数值差 `2.845e−8/2.014e−4`。4/6/8 kHz 的原生参考与各门仍以旧 MAT/正式报告为准，不把九点 CSV 的空变体栏误读为零。所有“通过”限此离散表示、域、支撑与经验数值门；FE 不是严格连续 Helmholtz 真值。若某新点参考门失败，停止该点后续物理比较和整个顺序队列，保留日志/失败变体，先只读复核输入、SHA、配置和数值原因；任何有界加密或变体重试须另行授权并维持旧门，无法合格则报告 `REFERENCE_INCONCLUSIVE`，不计入预测成功率。7.5 kHz 不在本轮补算或改门。

## 6. 成本情景、资源门与 STOP/GO

既有 5/7 kHz 新频点完整远端进程 `27/33 s`，四盲测为 `29/33/34/34 s`；这些含 MATLAB 启动与文件 I/O，但 5/7 核内部 `17.238/23.648 s`，说明不能把核墙钟当总作业成本。5/7 七进程含诊断/绘图审计共 `129 s`；四点另 MATLAB 审计 `11 s`，合计 `141 s`。历史四点预算 `400 s`，不结转。本设计按新四点**每点**预算：MATLAB 启动/调度 `15 s`、完整 FE 参考序列 `65 s`、FullFK 五配置 `25 s`、原生 MAT/CSV 与退出记录 `15 s`，合 `120 s/点`；另 SHA/独立审计 `80 s`，一次失败/变体余量 `160 s`，**建议下一轮总上限 720 s、单点 150 s**。这是待批准保守规划，并非由历史平均推出的可靠上界；若需要 L48、更密网格或参考求积加密，必须停在原门并重估，不得把超额隐入余量。六点扩展建议另立总上限 `1080 s`（六点×120 + 80 审计 + 280 余量），必须在四点方案完成后单独批准，不自动继承任何余额。65 点逐点 FE 将是至少 56 个旧点外新频率，绝非本计划成本范围；129/257 点密集物理扫频更不在本预算。

每个获准远端作业先按原 [SSH 与短回执协议](codex_token_execution_protocol.md)核代码/输入 SHA、R2023b、独立目录、30% 真实物理 RAM 余量、CPU/负载、磁盘及当前任务进程；不用 swap 放行。旧四点最大完整 RSS `2,648,588 kB`，旧新增工作集估计 `1,556,480 kB`，二者口径不同；建议用 **至少 3 GiB 增量 RAM 预留**再要求 `MemAvailable−3 GiB≥0.30 MemTotal`，磁盘建议预留 2 GiB，并在下一轮按真实文件量复核。单作业与累计墙钟、超时、实际 RSS 和磁盘均入检查点。远端共享设备负载异常或余量不足即停止，不盲重启；超时先检查原 job/checkpoint。

**STOP 1 参考：**任一真实边界、阶数、网格、域、尾界、出射、回放或 FullFK 数值门不合格，先停并报告 `REFERENCE_INCONCLUSIVE`；可信 FE/FullFK 对照未成立，不能给重建 PASS。**STOP 2 预测：**任一新常规或压力点未过冻结的 `e_R<1e−3`、新增目标或相位/跨频规则，报告该组失败及全部近零点，不以组平均或旧盲测稀释；不继续宣称该网格已验收。**STOP 3 成本：**RAM/负载/磁盘、150 s 单点或建议 720 s 总额触限时，保存证据并停；预算是下一轮需批准的上限建议，本 Goal 没有计算授权。只有参考门、两组逐点预测门、独立审计和时窗/端点检查均通过，才可说“固定案例的有限频点重建筛查支持 65 点预测网格”；对未知散射长尾及窗收敛未闭合前仍不能宣布无混叠宽带、认证 CIR、通信 BER/PER 或原 PM 资格。
