## 1. 本轮真正要回答的问题

在实际平均水深 100 m、发射机物理离底高度 0 m 的环境中，使用正常距离—深度
坐标、同一确定性一维粗糙海面，比较不同近垂直收发几何的 Bellhop 结果，并展示
完整声线扇区及全部接收贡献路径，包括海面、海底和多次反射。

目的不是重新证明 PE marching，也不沿用 500 m 人工海底得到的路径数和全信道
作为 100 m 环境的结论。后续若比较 PE，只能比较两边共同包含且同源的路径；
Bellhop 含海底的完整多途响应不能直接等同于当前 PE 的直达加一次海面反射。

归档和计划阶段已完成。用户随后明确接受三个数值离底距离，因此开始新的
Bellhop 边界源小检查；通过门槛前不启动角度/频率扩展，不运行 PE、通信或 Monte Carlo。

## 2. 环境和参数约定

| 项目 | 新方案 |
|---|---|
| 物理坐标 | 平均海面 z=0；z 向下为正 |
| 平均水深 / 平海底 | 100 m / z=100 m；粗糙面导致局部水深变化 |
| 发射机 | x=0，物理 z=100 m，离底 0 m，不擅自抬高 |
| 接收机 | 继续采用物理 z=3 m；本次用户未改变此项 |
| 水体 | 均匀 c=1500 m/s，密度 1000 kg/m³ |
| 海面 | 固定三余弦一维剖面、压力释放边界；不按角度重新生成/归一化 |
| 海底测试模型 | 均匀流体半空间，纵波声速 1800 m/s、密度 2000 kg/m³、纵波吸收 0.5 dB/波长、剪切波声速 0 |
| 海底参数性质 | 可复现的假设测试底质，不声称是实测底质；密度写入 Bellhop 时为 2 g/cm³，吸收使用 W 单位约定 |
| 发射定义 | 暂保留该 Bellhop-only 实验的单位幅度 Cartesian line source X，向水体上方发射；不是生产 PE Gaussian 源，也不是实测换能器 |
| 频率 | 先 4 kHz；完成后只选有意义的代表/最差 case 检查 6 和 8 kHz；本阶段不直接跑 65 点宽带 |
| 发射采样 | 所有 case 统一为 -89.9999° 至 -60°，A/E 10001 波束，代表性 R 扇区 1001 条 |
| 收发几何角 | 85、87、88、89、89.5、89.75、89.875、89.9375、89.96875、89.99° |
| 水平偏移 | r=(100-3)/tan(theta)；theta 是 Tx--Rx 连线夹角，不是所有声线的发射角 |
| 首选步长 | 0.02 m，所有 case 相同；仅有明确数值异常时做局部复核 |

粗糙海面继续采用可由保留源码重新生成的确定性定义：

`eta(x)=0.045*cos(2*pi*x/6+0.30)+0.020*cos(2*pi*x/2.2-1.10)+0.010*cos(2*pi*x/0.9+2.00)`。

不从 `cash/` 加载海面。剖面显式覆盖所有声线会访问的范围，包括反向传播的负
距离。初始统一采用 x=-12..12 m、0.01 m 间隔；若有效接收贡献受范围终止影响，
再对相关 case 扩大同一公式的覆盖范围，不对不同角度使用不同终止框。

若 Bellhop 输入需要将剖面整体下移 1 m，则海面、海底、Tx、Rx 一起变换：
海面 `1+eta(x)`、海底 101 m、物理 Tx 101 m、Rx 4 m。绘图一律减去 1 m，
显示实际物理深度；海底必须标为 100 m。计算终止深度可略大于输入海底，如
101.1 m，确保底反射先被处理；这个终止深度不是新的物理海底。

## 3. 已发现的硬限制：安装版本不直接接受零离底源

本地 `AcousticsToolbox_2017/Bellhop/bellhop.f90` 的 `TraceRay2D` 第 475–477 行
检查 `DistBegTop <= 0 OR DistBegBot <= 0` 后直接返回，并注明 source must be
within the medium。执行后补充：在该检查前，`readin.f90` 第 100–102 行还会把
源限制到 `ZMax-100*SPACING(SNGL(ZMax))`，因此普通输入中的近底源可能先被
自动上移，并非一定原样交给 TraceRay。两种行为都不构成严格边界声源的实现。

**用户已明确接受以下水侧极限近似（2026-08-27）：**

- 物理定义始终为 `source_height_above_bottom_m=0`；数值输入单独记录
  `source_boundary_epsilon_m`，水侧源深度为 `100-epsilon`。
- 只做三个 epsilon：1e-3、1e-4、1e-5 m，先在平面海面 4 kHz 的一个代表性
  几何检查直达/一次海面反射，再复核一个粗糙面 case。保持物理 Rx 横向位置
  不变；实际数值 Tx--Rx 夹角差另行记录。
- 同类路径从 1e-4 到 1e-5 m 的 TL、相位、时延变化分别不超过
  0.01 dB、0.002 rad、1 microsecond，才以 1e-5 m 作为边界水侧极限近似。
- 这不是把发射机实际安装高度改成 1 cm 或 1 m，也不通过相位/幅度拟合消除
  差异；但依然必须标明它是数值极限近似，不能写成精确 0 m 输入已通过。
- 将初始向上水侧声场作为已给定声源，不再额外叠加一个重合的“初始底反射源”
  或乘一次海底反射系数；海底反射只作用于后续返回海底的声线。
- 若用户要求输入必须严格 0 m、或者极限检查不稳定，暂停后续角度扫描。需要
  另行讨论边界源实现/其他 Bellhop 版本；本计划不授权修改 Bellhop 核心或 PE。

## 4. 简单执行顺序

1. **建立新环境。** 新增独立的 100 m 验证入口；优先复用现有解析器/绘图逻辑，
   不调用旧脚本的 500 m 默认设置。记录实际 `.env/.prt`、源 epsilon、物理/输入
   坐标及单位。海底反射参数一致地用于全部 case。
2. **处理边界源。** 用户接受水侧极限后执行上述小检查；未通过即停止。
3. **先做少量 4 kHz 案例。** 平面控制案例及固定粗糙面 89°、89.5°、89.99°；
   确认正常传播、底反射计数和完整轨迹。仅有明显问题时复查波束/步长，不新增
   大规模参数扫描。
4. **补齐角度并分类比较。** 用同一扇区、海面和范围运行完整 10 个几何角。
   分开报告直达、一次海面反射、含海底多途及全部 arrival 的相干响应。记录
   幅度、相位、时延和路径数；不能把不同 bounce 类混成同一条路径跟踪。
5. **绘图并有限扩频。** 全部 E 接收贡献轨迹由独立 R 重建，不筛掉弱路径或
   海底多次反射；完整 R 扇区保留所有已计算回程。给出物理 0–100 m 全图与
   海面/Rx 放大。只对选出的少量 case 扩展到 6、8 kHz。
6. **报告并停在结论。** 最小检查包括 A/E 物理输入一致、文件完整、深度变换
   正确、全部记录计数及 MATLAB checkcode。无关 PE/通信回归、源重设计、
   随机海面 Monte Carlo 不在本轮范围。

Bellhop 的 E 记录是对接收点有贡献的有限宽波束中心线，不自动等于精确穿过点
接收机的几何 eigenray。必须保留并报告实际偏离距离，不能把端点接到 Rx。
“全部”仅指统一有限计算范围和 Bellhop 终止规则内的全部记录，不表示无穷
多次反射全部被计算。若存在明显远离 Rx 的贡献，先标记其数值可信度，不能
仅因 `.arr` 有记录便称为真实到达路径。

角度相近不自动证明等价于 90°。原先 0.1 dB、0.02 rad、10 microseconds
门槛仅用于已匹配路径/同类相干响应的相邻角度稳定性诊断；不通过则如实报告，
不逐角拟合、补造缺失路径或强行指定一个角度代替严格垂直。
