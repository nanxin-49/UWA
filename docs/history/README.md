# 历史资料区

本目录保存已经退出当前权威文档体系的原始规格与旧代码说明，用于追溯项目演进：

- `SSA.md`
- `BUBBLE_EXTENSION_SPEC.md`
- `README_CODE_STRUCTURE_AND_OUTPUTS.md`

这些文件保留原文和当时的根目录路径，因此可能与当前 `src/` 布局、公共字段语义、默认相位参考或验证状态不一致。后续开发不得只依据这里的内容修改代码。

当前依据顺序为：

1. 代码与测试；
2. 根目录 `vertical_comm_guide.md`；
3. `PROJECT_CONTEXT.md` 顶部当前状态索引及最新日期日志；
4. `reports/` 中对应正式验证报告；
5. 本目录历史材料仅作补充追溯。
