## 角度、负距离与严格垂直

本地`Bellhop/bellhop.f90:441`初始化方向为`[cos(alpha),sin(alpha)]/c`：0°向右，−90°向上，+90°向下；略小于−90°向左上。官方手册也说明负发射角朝海面：[Bellhop输入约定](https://www.oalib-acoustics.org/website_resources/AcousticsToolbox/manual/node61.html)。ENV接收距离单位为km，输出及绘图统一为m。

- 初始`[−89.999,−89.94]°`只发射右上声束；50束全图零压力比例50.14%，主要是左半平面未覆盖。500/2000束仍不能解决方向缺失。
- 另运行左上`[−90.06,−90.001]°`，与原右上独立解的左右对照复数相对差为`5.62e−8`。双侧窄扇`[−90.06,−89.94]°`直接计算整个负/正坐标网格，未镜像填图。
- 严格−90°单条声线成功：最大横向漂移`1.71e−10 m`，5次海面、5次海底反射。它说明几何追踪可用，**不能证明声场幅值可用**；同角度单束`CG R`声场全零。单束还具有`Dalpha=0`的退化，不代表含垂直束的完整角扇一律全零；51束跨轴诊断已单独保留。
- 原生`influence.f90:777–783`在点声源模式对每个`r=0`点设归一化factor=0，故整列压力为零。对z≠4950 m，这不是物理上的零声压；对z=4950 m、r=0，则同时是理想点源自身奇点。**水平距离零与源接收总距离零必须区分。** `X`线声源的归一化不同，但改变了源模型，不能作为原点点源声场的等价修复。
- 近轴还有`1/sqrt(abs(r))`归一化与有限角度离散耦合：近零的亮带需做角度收敛和独立幅值检查，不能当作垂直聚焦证据。原生`Cg R`射线中心帽形束也做了均匀介质诊断，有33.67%零网格，未提供可接受替代方案；不据此断言所有原生束类型均不可用。

34个运行中复压力NaN/Inf数为0，Unbounded beam警告为0；只有上述两组有总计388条轨迹存储警告。其余双侧主图零压力恰为1/401，即原生置零的轴列；窄角自由场控制的额外零值属于角扇未覆盖。`TL=−20log10|p|`在零压力处自然为Inf，绘图标灰并保留原始零值，未用70 dB填充。原始有限TL超出20～70 dB的值仍保留在MAT/CSV，色标仅控制显示。

独立匹配半空间均匀介质控制以`|p|=1/sqrt((4950−z)^2+x^2)`检查原生幅值，不做拟合。在z=1000/3000 m且`.1≤|x|≤(4950−z)tan(.055°)`的双侧窄扇内部，2000束的TL误差P95为`1.66e−5/2.05e−5 dB`；z=4900 m没有满足该条件的点，不能声称已验证。全角2000束在z=1000 m、x=.1 m处TL约54.98 dB，而解析值约71.93 dB，偏低16.95 dB；全横向控制TL误差P95达6.94 dB。这个控制直接否定了以近轴亮带的外观作为准确性的依据；它只验证幅值，不认证Munk全场或相位。

声线确实触海面并反射，原生小步处理产生约`1e−4 m`的边界越界点，原始RAY未裁改。海面`z=0`细网格诊断压力最大`2.21e−4`、中位`1.14e−4`，并非严格零；有限角扇、原生束重建和多途截断下，未认证压力释放边界的精确场满足。10 kHz波长约.15 m，近垂直驻波深度周期约.075 m；全深度5 m网格无法解析细干涉，不能把主图横纹当作已解析的物理条纹。另用`z=0:.01:1 m`细网格显示这一限制。

## 对原图的定性比较与最终回答

全角图出现轴线亮带、近源/近底高强度区和上部低强度区，与附件有部分外观相似；但条纹和轴线幅度随声束/步长明显变化。窄角扇的可信直接照射范围随接近源而收窄，不能填满论文图下方宽底部的完整场。因此，不通过镜像、平滑、增益偏移或填补轴列追求视觉一致。

1. **能否复现？** 本轮未能用当前原生二维点声源Bellhop可靠复现完整图12(b)，仅完成可重复的环境和部分定性结构复现；不是证明Bellhop对所有近垂直传播都失效。
2. **哪组最好？** 近垂直专项检查推荐`[−90.06,−89.94]°、8000束、STEP=.625 m、CG R`，无存储警告；它是本轮最充分的窄角检查，不是已收敛全场。限定50/500/2000时选2000束、.625 m。全场展示选对称全角2000束、.15625 m，但只作为未收敛诊断，不能用其漂亮轴带取代窄角验证。
3. **严格垂直与零距离限制？** 声线可追踪；严格单束相干场退化，点声源零水平距离整列被原生置零，且较小步长会触轨迹存储上限。近零极限还需角度密度与幅值控制。
4. **能否作为后续通信基础？** 可复用ENV、SSP、边界假设和声线检查流程；当前复场不能直接作为经验证的垂直通信信道响应。仍需非零距离接收点的复数幅相、多途完整性、角度/步长收敛，以及宽带验证。本轮没有实施这些通信阶段工作。
